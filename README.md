# 📩 Spam Email Detection using Machine Learning

## 🚀 Overview
This project classifies messages as **Spam** or **Not Spam** using the Naive Bayes algorithm.

## 🛠 Tech Stack
- Python
- Pandas
- Scikit-learn
- NLP (CountVectorizer)

## ⚙️ How It Works
1. Convert text into numerical features
2. Train Naive Bayes model
3. Predict whether message is spam
